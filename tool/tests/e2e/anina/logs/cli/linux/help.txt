## mandrake --help · the list of commands

[3.1s]
    ~ $ mandrake --help
    Mandrake corta o que o Claude Code coloca em volta do seu prompt, mede quanto isso economiza
    e refaz a sua pasta ~/.claude em qualquer máquina a partir de um perfil.
    
    Sem argumentos, mostra o estado desta máquina. Comece por `mandrake setup` e confira com `mandrake d
    octor`.
    
    Usage: mandrake [COMMAND]
    
    Commands:
      setup    Instala ou ajusta: pergunta item por item e aplica (--cli em linhas, --profile f --yes se
    m perguntar)
      doctor   Confere tudo: links, settings, plugins, shell, proxy e Claude Code
      bench    Mede de verdade: os mesmos prompts pelo claude -p sem e com Mandrake (gasta 2 requisições
     curtas por prompt)
      watch    Tela ao vivo das requisições: sem Mandrake à esquerda, com Mandrake à direita
      hex      Uma requisição antes e depois do corte, lado a lado em hex (precisa de auditoria ligada)
      audit    Lista as requisições cujo corpo foi guardado (com [proxy] audit = true no perfil)
      capture  Escreve a pasta ~/.claude atual como perfil, para levar a outra máquina
      link     Links da pasta ~/.claude: plan mostra, apply aplica, rollback desfaz
      proxy    O proxy local: run, install, uninstall, status
      help     Print this message or the help of the given subcommand(s)
    
    Options:
      -h, --help
              Print help (see a summary with '-h')
    
      -V, --version
              Print version
    ~ $
