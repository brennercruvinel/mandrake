### 03-installed

Mandrake: corta o que o Claude Code coloca em volta do seu prompt e mede a economia.

Como funciona, em duas camadas:
  1. prompt-trim (dentro do Claude Code) ........ ligado
     tira o prompt padrão, os lembretes, data, pasta e as descrições longas das tools,
     e põe no lugar o core (data/prompt/cores/coding.md) nas sessões sem soul
  2. proxy local 127.0.0.1:8787 (entre o Claude Code e a API) ... ligado
     tira as tags <system-reminder> e os campos metadata; mede tokens antes e depois
     sessões abertas por um shell com o Mandrake usam o proxy quando ele responde;
     se ele estiver fora, vão direto para a API, sem quebrar

Pelo proxy passaram 0 requisições.
Para ver o corte: `mandrake compare` mostra o que o Claude Code envia sem e com o Mandrake,
sem gastar nada. `mandrake bench` mede de verdade, com 2 requisições por prompt.
